# ฝั่งผู้ดูแลระบบ ลำดับที่ 4: ระบบตรวจสอบ ความปลอดภัย และปฏิบัติตามกฎหมาย (`4. ระบบตรวจสอบ ความปลอดภัย และปฏิบัติตามกฎหมาย`)

- **อ้างอิงอาร์ติแฟกต์ที่เกี่ยวข้อง:**
  - ตารางแบ่งฟีเจอร์ฝั่ง **`ผู้ดูแลระบบ`** ลำดับที่ **`4`**
  - บทบาท Stakeholder:
    - `SH-05`: ฝ่ายดูแลลูกค้า / ทีม Support
    - `SH-07`: ผู้ดูแลระบบ / ฝ่ายไอทีและข้อมูล
    - `SH-09`: เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (`DPO`)
    - `SH-10`: ผู้ตรวจสอบ (`Auditor`) / หน่วยงานกำกับดูแล (`เทศบาล / กทม.`)
  - การตัดสินใจทางเทคนิค: **`P-07` (`TASKS-ROUTE T-10`)**: บันทึก `Audit Trail Log` ทุกครั้งที่กดรับงานและทำธุรกรรม
  - ความต้องการและข้อจำกัดที่เกี่ยวข้อง: `REQ-SEC-002`, `CT-01` (PDPA หน้า 44)

---

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **ระบบบันทึกร่องรอยตรวจสอบธุรกรรม (`Audit Trail Log` — `P-07`, `T-10`):**
   - บันทึกประวัติการเปลี่ยนแปลงข้อมูลสำคัญแบบแก้ไขย้อนหลังไม่ได้ (`Immutable Log`) เช่น การกดรับงานของซาเล้ง (สำเร็จ/ล้มเหลว พร้อมเวลาที่ถึง Server ตาม `T-10`), การแก้ไขราคากลางประจำวัน, ประวัติการยืนยันน้ำหนักและซื้อขาย, และการทำธุรกรรมเงินสด/ดิจิทัล สำหรับให้ผู้ตรวจสอบ (`Auditor / SH-10`) ดึงข้อมูลย้อนหลัง
2. **ระบบควบคุมการเข้าถึงตามบทบาท (`Role-Based Access Control — RBAC`):**
   - แยกสิทธิ์การมองเห็นและจัดการข้อมูลของทีม Support (`SH-05`), ฝ่ายไอที/ดูแลระบบ (`SH-07`), เจ้าหน้าที่คุ้มครองข้อมูล (`DPO / SH-09`), และผู้ตรวจสอบบัญชี (`SH-10`) อย่างเข้มงวด
3. **ระบบจัดการความคุ้มครองข้อมูลและรายงานชุมชน (`PDPA & Anonymized Report` — `CT-01`, `REQ-SEC-002`):**
   - ควบคุมการปิดบังข้อมูลส่วนบุคคล (`Data Masking` เช่น ที่อยู่ `addressText`, พิกัด `geoPoint`, เบอร์โทรศัพท์ `phone`) และกำหนดระยะเวลาจัดเก็บพิกัดซาเล้ง (`Saleng.currentLocation` ตาม `Q-04`)
   - ส่งออกรายงานสถิติปริมาณขยะรีไซเคิลชุมชนแบบไม่ระบุตัวตน (`Anonymized Report`) ให้แก่สำนักสิ่งแวดล้อม กทม. / เทศบาล (`SH-10`)

---

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria`)
- **`AC-A04-01` (`Audit Trail Log` — `P-07`, `T-10`):** ทุกการกดรับงาน (สำเร็จและล้มเหลว) การแก้ไขราคากลาง และการยืนยันยอดชำระเงิน ต้องถูกบันทึกลง `Audit Trail Log` พร้อมระบุวันเวลาและผู้กระทำ
- **`AC-A04-02` (`RBAC Enforcement`):** ระบบจำกัดสิทธิ์การเข้าถึงหน้าจอและ API ตามบทบาท (`Seller`, `Collector`, `Support`, `Admin`, `Auditor`) อย่างเคร่งครัด
- **`AC-A04-03` (`PDPA Masking & Anonymized Community Report` — `REQ-SEC-002`, `CT-01`):** รายงานสถิติปริมาณขยะรีไซเคิลที่ส่งออกให้หน่วยงานภายนอก (`กทม. / เทศบาล`) ต้องไม่มีข้อมูลส่วนบุคคล (`PII` เช่น ชื่อ เบอร์โทร บ้านเลขที่ หรือพิกัดบ้านของผู้ขาย) ปะปนอยู่ 100%
