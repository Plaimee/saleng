# บันทึกการตรวจหน้าจอเทียบกับ Mockup 6 ข้อ (`ui-review.md`) — ฟีเจอร์ `UC-04`

เอกสารนี้บันทึกผลการ **อ่านตรวจหน้าจอ (Static UI Inspection)** เทียบกับไฟล์ต้นแบบใน [`mockups/`](../mockups/) และส่วนที่ 12 ของ [`spec.md`](../spec.md) โดยตรวจครบ 6 ข้อต่อ 1 หน้าจอ (รวม 3 หน้าจอ = 18 ข้อตรวจ)
