# ฝั่งผู้ซื้อ (ซาเล้ง) ลำดับที่ 6: ระบบคิดเงินและออกใบเสร็จ (`6. ระบบคิดเงินและออกใบเสร็จ`)

- **อ้างอิงอาร์ติแฟกต์ที่เกี่ยวข้อง:**
  - ตารางแบ่งฟีเจอร์ฝั่ง **`ผู้ซื้อ`** ลำดับที่ **`6`**
  - In Scope: **`SC-03: การบันทึกสรุปน้ำหนัก รายการขยะ และยอดเงินหลังการซื้อขายเสร็จสิ้น`**
  - Use Case Diagram: **`UC-06: ชำระเงินและออกใบเสร็จดิจิทัล`** และ **`UC-10: บันทึกรับเงินสดหน้างาน`**
  - ความต้องการที่เกี่ยวข้อง: **`REQ-FN-005`**, `REQ-DAT-001`, `CT-02` (หน้า 44: รองรับโหมดกึ่งออฟไลน์ในจุดอับสัญญาณขณะชั่งน้ำหนักและบันทึกราคา)

---

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **คำนวณราคารับซื้อตามน้ำหนักและเรตราคา (`REQ-FN-005`, `REQ-DAT-001`):**
   - เมื่อซาเล้งถึงบ้านผู้ขาย (`E4 -> S5: ถึงจุดนัดหมายและชั่งของ`) ซาเล้งชั่งน้ำหนักจริงหน้างานและกรอกค่าน้ำหนักจริง (`actualWeight`) แยกตามชนิดวัสดุลงในแอป
   - ระบบคำนวณยอดเงินตามเรตราคารับซื้อ (`REQ-DAT-001`) และส่งตัวเลขน้ำหนักจริงให้ผู้ขายกดยืนยันบนหน้าจอ (`REQ-FN-005`: บล็อกไม่ให้ออกใบสรุปยอดเงิน 100% จนกว่าผู้ขายจะกดยืนยัน)
   - รองรับการบันทึกข้อมูลการชั่งน้ำหนักและราคาในจุดอับสัญญาณแล้วซิงก์เมื่อมีสัญญาณ (`CT-02` หน้า 44)
2. **ชำระผ่าน `เงินสด / QR Code / PromptPay` (`UC-06`, `UC-10`, `DP-02`):**
   - หลังจากผู้ขายกดยืนยันน้ำหนักจริงแล้ว (`E5 -> S6: รอยืนยันชำระเงิน`) ซาเล้งสามารถชำระเงินค่าของเก่าให้ผู้ขายด้วย **`เงินสด`** (`UC-10`) หรือสแกนจ่ายผ่าน **`QR Code / PromptPay`** (`UC-06`, `DP-02`)
3. **ออกใบเสร็จสรุปรายการดิจิทัล (`SC-03`):**
   - เมื่อชำระเงินเสร็จสมบูรณ์ (`E6 -> S7: สำเร็จ / ปิดงาน`) ระบบออกใบเสร็จสรุปรายการดิจิทัลที่แสดงรายการขยะ น้ำหนักจริง และยอดเงินสุทธิให้ทั้งซาเล้งและผู้ขาย

---

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria`)
- **`AC-B06-01` (Actual Weight Recording & Seller Confirmation Gate — `REQ-FN-005`):** ซาเล้งต้องกรอกค่าน้ำหนักจริงแยกตามชนิดวัสดุ และระบบต้องรอให้ผู้ขายกดยืนยันตัวเลขน้ำหนักก่อนจึงจะปลดล็อกให้ออกใบสรุปยอดชำระเงินได้ (`100%`)
- **`AC-B06-02` (Cash & QR/PromptPay Payment — `UC-06`, `UC-10`):** ซาเล้งสามารถบันทึกการจ่ายเงินด้วยเงินสดหรือสแกนชำระผ่าน `QR Code / PromptPay` ได้
- **`AC-B06-03` (Digital Summary Receipt — `SC-03`):** หลังชำระเงินสำเร็จ ระบบสร้างใบเสร็จสรุปรายการดิจิทัลและเปลี่ยนสถานะงานเป็น `S7 (Completed)`
