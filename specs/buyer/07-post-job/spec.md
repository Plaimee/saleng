# ฝั่งผู้ซื้อ (ซาเล้ง) ลำดับที่ 7: ระบบหลังจบงาน (`7. ระบบหลังจบงาน`)

- **อ้างอิงอาร์ติแฟกต์ที่เกี่ยวข้อง:**
  - ตารางแบ่งฟีเจอร์ฝั่ง **`ผู้ซื้อ`** ลำดับที่ **`7`**
  - ข้อมูลสัมภาษณ์ซาเล้ง:(การเก็บพิกัดลูกค้าประจำ และการจัดการกรณีไปถึงหน้าบ้านแล้วของจริงไม่ตรงกับที่แจ้ง หรือลูกค้าไม่อยู่บ้าน `No-show`)
  - Use Case & State Machine ที่เกี่ยวข้อง: `UC-13: จัดการข้อพิพาทและงานตกค้าง`, `MD-STM-04` (`E9: ร้องเรียน/ข้อพิพาท -> S9` หน้า 63)

---

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **บันทึกประวัติการรับซื้อ:**
   - แสดงประวัติงานที่ซาเล้งรับซื้อสำเร็จทั้งหมด (`S7: Completed`) พร้อมสรุปน้ำหนักวัสดุรวมรายวัน/รายเดือน รายจ่ายค่าซื้อของเก่า และใบเสร็จดิจิทัลย้อนหลัง
2. **บันทึกพิกัดลูกค้าประจำ:**
   - ซาเล้งสามารถกดปักหมุดบันทึกบ้านผู้ขายที่ขายของเก่าสม่ำเสมอไว้ในรายการ **`"ลูกค้าประจำ"`** เพื่อวางแผนเส้นทางวิ่งรถในรอบสัปดาห์ถัดไปได้สะดวก (สอดคล้องกับพฤติกรรมซาเล้งในหน้า 28 และ 32)
3. **รายงานผู้ขาย (กรณีข้อมูลไม่ตรง — `E9 -> S9`, `UC-13`):**
   - หากซาเล้งเดินทางไปถึงหน้างานแล้วพบว่าข้อมูลของเก่าไม่ตรงกับที่แจ้งไว้มาก (เช่น ของปนเปื้อนหนัก ปริมาณน้อยกว่าที่แจ้งมาก หรือผู้ขายไม่อยู่บ้านตามนัด `No-show`) ซาเล้งสามารถกดรายงานผู้ขายพร้อมแนบรูปถ่ายหน้างานส่งไปยังศูนย์ควบคุมข้อพิพาทของ Admin (`Dispute Resolution`) ได้ทันที

---

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria`)
- **`AC-B07-01` (Purchase History Log):** ซาเล้งสามารถดูประวัติการรับซื้อย้อนหลังพร้อมยอดรวมน้ำหนักและจำนวนเงินได้
- **`AC-B07-02` (Regular Customer Bookmark):** ซาเล้งสามารถกดบันทึกพิกัดผู้ขายเป็น `"ลูกค้าประจำ"` หลังจบงานได้
- **`AC-B07-03` (Seller Mismatch / No-Show Report — `UC-13`, `S9`):** ซาเล้งสามารถกดรายงานผู้ขายกรณีข้อมูลหน้างานไม่ตรงหรือผู้ขายไม่อยู่ตามนัด พร้อมแนบรูปหลักฐานส่งเข้าคิวตรวจสอบของ Admin ได้
