# ฝั่งผู้ซื้อ (ซาเล้ง) ลำดับที่ 3: ระบบประเมินงานก่อนรับ (`3. ระบบประเมินงานก่อนรับ`)

- **อ้างอิงอาร์ติแฟกต์ที่เกี่ยวข้อง:**
  - ตารางแบ่งฟีเจอร์ฝั่ง **`ผู้ซื้อ`** ลำดับที่ **`3`**
  - User Story (3Cs บนหน้า 62): **`Feature: แสดงระยะทางและค่าน้ำมันโดยประมาณก่อนรับงาน`** (`Card 02` บนซ้ายของหน้า 62)
  - ความต้องการที่เกี่ยวข้อง: `REQ-FN-002`, `REQ-QA-002`, `REQ-OP-002`, `REQ-FN-003`, `REQ-FN-004`, `REQ-CON-003`

---

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **ดูรายละเอียดงาน ขนาด รูปถ่าย ราคาประเมิน และระยะทาง/ค่าน้ำมันโดยประมาณ (`AC-04-02`, `AC-04-03`, `Card 02` หน้า 62):**
   - เมื่อซาเล้งเลือกดูรายละเอียดคำขอ ระบบแสดง:
     - ประเภทของเก่า (รวมถึงหมวด `'ของชิ้นใหญ่แบบเหมาจ่าย'` เช่น ตู้เย็น `200–300 บาท` หรือ `'วัสดุบรรจุลังแยกเฉพาะ'` ตาม `REQ-FN-003`)
     - น้ำหนัก/ปริมาณประเมิน รูปถ่ายของเก่า (`REQ-FN-004`) และสัญลักษณ์แจ้งเตือนกรณีผู้ขายขอคนช่วยยกของหนัก (`REQ-FN-004`)
     - ช่วงราคาประเมิน (`totalEstimatedPrice`)
     - **ระยะทางโดยประมาณ (`RouteMatch.calculatedDistance`) และค่าน้ำมันโดยประมาณ** คำนวณจากอัตราสิ้นเปลืองเฉลี่ย โดยระยะทางที่แสดงต้องคลาดเคลื่อนจากระยะทางจริงไม่เกิน `15%` (`REQ-QA-002`, `AC-04-11`)
2. **สลับสถานะความพร้อมรับงาน (`Online / Offline`):**
   - ซาเล้งสามารถกดสลับสถานะตัวเองระหว่าง `"พร้อมรับงาน (Online)"` และ `"พักรับงาน (Offline)"` ได้
3. **ตรวจสอบความจุของรถก่อนรับงาน (`REQ-CON-003`, `REQ-FN-003`):**
   - เปรียบเทียบน้ำหนัก/ขนาดของรายการที่จะรับกับความจุรถบรรทุกที่เหลืออยู่ของซาเล้ง เพื่อให้จัดสรรพื้นที่รถได้ถูกต้อง 100% ก่อนออกเดินทาง

---

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria` — ตรงตาม `Card 02` หน้า 62 และ `AC-04-03`, `AC-04-10`, `AC-04-11`)
- **`AC-B03-01` (Distance & Fuel Cost Estimation — `Card 02` Pass Case, `AC-04-03`, `AC-04-11`):** เมื่อซาเล้งเปิด `GPS` และเปิดดูรายละเอียดงาน ระบบแสดงประเภท น้ำหนักประเมิน รูปถ่าย ราคาประเมิน พื้นที่ระดับตำบล/แขวง ระยะทางโดยประมาณ และค่าน้ำมันโดยประมาณ โดยระยะทางคลาดเคลื่อนจากระยะทางจริงไม่เกิน `15%` (สุ่มตรวจ 20 จุดภาคสนาม)
- **`AC-B03-02` (Maps API Timeout Handling — `Card 02` Exception Case, `AC-04-10`, `E3`):** เมื่อบริการแผนที่ภายนอก (`Maps API`) ไม่ตอบสนองเกินเวลาที่กำหนด ระบบแสดงข้อความ `"ไม่สามารถคำนวณระยะทางได้ในขณะนี้ / แจ้งให้ลองใหม่"` โดยไม่ทำให้หน้าจอค้างและไม่แสดงระยะทางที่ไม่ได้คำนวณจริง
- **`AC-B03-03` (Online/Offline Toggle & Vehicle Capacity Check — `REQ-CON-003`):** ซาเล้งสามารถสลับสถานะ `Online/Offline` และเห็นข้อมูลขนาด/น้ำหนักเทียบกับความจุรถก่อนกดรับงานได้
