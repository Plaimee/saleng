# ฝั่งผู้ขาย ลำดับที่ 5: ระบบนัดหมายและติดตามสถานะ (`5. ระบบนัดหมายและติดตามสถานะ`)

- **อ้างอิงอาร์ติแฟกต์ที่เกี่ยวข้อง:**
  - ตารางแบ่งฟีเจอร์ฝั่ง **`ผู้ขาย`** ลำดับที่ **`5`**
  - Use Case Diagram: **`UC-07: สร้างคำขอนัดหมายรับซื้อ`**
  - Business Rule: **`BR-03: นโยบายการยกเลิกนัดหมาย — ผู้ขายยกเลิกได้เฉพาะก่อนที่ซาเล้งกดยืนยันออกเดินทางแล้วเท่านั้น`**
  - State Machine: **`MD-STM-04` สถานะคำขอรับซื้อ `S1` ถึง `S9` และ Events `E1..E11`**

---

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **เลือกวันเวลานัดหมายและยืนยันรายละเอียด (`UC-07`):**
   - ผู้ขายเลือกวันที่และช่วงเวลาที่สะดวกอยู่บ้าน (ตาม `EV-012` นัดวัน-เวลาล่วงหน้า หรือเรียกมารับตามช่วงเวลา) และตรวจสอบรายการของเก่าพร้อมที่อยู่นัดหมายก่อนกดยืนยัน
2. **ส่งคำขอนัดหมายหาซาเล้งในพื้นที่ (`E1: ส่งคำขอ`):**
   - เปลี่ยนสถานะคำขอจาก `S1: ฉบับร่าง (Draft)` เป็น `S2: รอผู้รับซื้อ (Pending / Open)` เพื่อกระจายเข้าสู่ระบบค้นหางานในเส้นทางของซาเล้ง (`UC-04`)
3. **ติดตามสถานะคำขอ (`MD-STM-04` หน้า 63):**
   - ผู้ขายติดตามสถานะคำขอแบบเรียลไทม์ครบทั้ง 9 สถานะ:
     - `S1: ฉบับร่าง (Draft)`
     - `S2: รอผู้รับซื้อ (Pending / Open)`
     - `S3: มีผู้รับงานแล้ว (Assigned / Accepted)` — แจ้งเตือนผู้ขายทันทีเมื่อซาเล้งกดรับงาน (`UC-04 ขั้น 7`)
     - `S4: กำลังเดินทาง (In-Transit)` — เมื่อซาเล้งเริ่มออกเดินทาง (`E3`)
     - `S5: ถึงจุดนัดหมายและชั่งของ (Arrived & Weighed)` — เมื่อซาเล้งถึงหน้างาน (`E4`)
     - `S6: รอยืนยันชำระเงิน (Pending Payment)` — เมื่อผู้ขายกดยืนยันราคาสุทธิ/น้ำหนัก (`E5`)
     - `S7: สำเร็จ / ปิดงาน (Completed)` — เมื่อชำระเงินสำเร็จ (`E6`)
     - `S8: ยกเลิก (Cancelled)` — เมื่อยกเลิกคำขอ (`E8`) หรือหมดเวลา (`E11`)
     - `S9: ระงับชั่วคราว / ข้อพิพาท (Disputed / Frozen)` — เมื่อร้องเรียน/ข้อพิพาท (`E9`)
4. **ยกเลิก หรือแก้ไขนัดหมาย (`BR-03` หน้า 62):**
   - **กฎธุรกิจ `BR-03`:** นัดหมายหนึ่งรายการมีสถานะได้เพียงสถานะเดียวในแต่ละขณะ และ **ผู้ขายยกเลิกหรือแก้ไขได้เฉพาะก่อนที่ซาเล้งกดยืนยันออกเดินทางแล้ว (`S4: กำลังเดินทาง`) เท่านั้น**
5. **รับการแจ้งเตือนก่อนซาเล้งถึงบ้าน (`Action Enabler` ใน `BR-03` หน้า 62):**
   - เมื่อมีซาเล้งกดรับงาน (`S3`) และเมื่อเหลือเวลาน้อยกว่าที่กำหนดก่อนนัดหมายหรือซาเล้งเริ่มออกเดินทาง (`S4`) ระบบส่งการแจ้งเตือนย้ำถึงผู้ขาย

---

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria`)
- **`AC-S05-01` (Order Submission `S1 -> S2` — `UC-07`):** เมื่อผู้ขายเลือกวันเวลานัดหมายและกดยืนยัน คำขอต้องเปลี่ยนสถานะจาก `S1 (Draft)` เป็น `S2 (Pending / Open)`
- **`AC-S05-02` (Pre-Transit Cancellation Rule — `BR-03`):** ผู้ขายสามารถกดยกเลิกนัดหมายได้เมื่อสถานะเป็น `S1`, `S2`, หรือ `S3` (`-> S8: ยกเลิก`) แต่หากซาเล้งกดเริ่มเดินทางเข้าสู่สถานะ `S4 (กำลังเดินทาง)` แล้ว ระบบต้องบล็อกการยกเลิกของผู้ขายทันที
- **`AC-S05-03` (Status Notification):** เมื่อซาเล้งกดรับงาน (`S2 -> S3`) หรือกดเริ่มเดินทาง (`S3 -> S4`) ผู้ขายต้องได้รับการแจ้งเตือนพร้อมข้อมูลโปรไฟล์ของซาเล้งที่รับงาน
