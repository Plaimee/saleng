# ฝั่งผู้ขาย ลำดับที่ 6: ระบบชำระเงินและตรวจสอบ (`6. ระบบชำระเงินและตรวจสอบ`)

- **อ้างอิงอาร์ติแฟกต์ที่เกี่ยวข้อง:**
  - ตารางแบ่งฟีเจอร์ฝั่ง **`ผู้ขาย`** ลำดับที่ **`6`**
  - In Scope: **`SC-03: การบันทึกสรุปน้ำหนัก รายการขยะ และยอดเงินหลังการซื้อขายเสร็จสิ้น`** และ **`SC-05: ชำระเงินผ่านแอปให้คะแนนหลังจบงาน`**
  - Use Case Diagram: **`UC-06: ชำระเงินและออกใบเสร็จดิจิทัล`** และ **`UC-10: บันทึกรับเงินสดหน้างาน`**
  - ความต้องการที่เกี่ยวข้อง: **`REQ-FN-005`** (หน้า 61: บังคับบันทึกค่าน้ำหนักจริงและให้ผู้ขายกดยืนยันตัวเลขน้ำหนักก่อนสรุปยอดชำระเงิน `100%`) และ `REQ-006` (หน้า 60: รองรับเงินสดและใบเสร็จดิจิทัล)

---

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **ตรวจสอบและกดยืนยันตัวเลขน้ำหนักชั่งจริงก่อนสรุปยอดเงิน (`REQ-FN-005` หน้า 61):**
   - เมื่อซาเล้งชั่งของหน้างาน (`S5: ถึงจุดนัดหมายและชั่งของ`) และกรอกค่าน้ำหนักจริงแยกตามชนิดวัสดุลงในระบบ
   - ผู้ขายต้องตรวจสอบและ **กดยืนยันตัวเลขน้ำหนักบนหน้าจอของตนเองก่อน** ระบบจึงจะอนุญาตให้ออกใบสรุปยอดเงิน (`S6: รอยืนยันชำระเงิน`)
   - **กฎเหล็ก (`REQ-FN-005`):** หากผู้ซื้อกรอกน้ำหนักแล้ว แต่ผู้ขายยังไม่ได้กดยืนยัน ระบบต้องบล็อกไม่ให้ออกใบสรุปยอดเงิน `100%`
2. **เลือกวิธีรับเงิน (`เงินสด / QR Code / โอน` — หน้า 62, `UC-06`, `UC-10`):**
   - รองรับการเลือกรับเงินทั้งแบบ **`เงินสด`** หน้างาน (`UC-10`, `EV-010`) และแบบดิจิทัล **`QR Code / PromptPay / โอนเงิน`** (`UC-06`, `DP-02`)
3. **ตรวจสอบและยืนยันใบเสร็จดิจิทัล (`SC-03`):**
   - แสดงใบเสร็จดิจิทัลสรุปรายการวัสดุ น้ำหนักจริงที่ยืนยันแล้ว ราคาต่อหน่วย และยอดเงินสุทธิ
4. **ยืนยันการรับเงิน (`E6: ชำระเงินสำเร็จ -> S7: สำเร็จ / ปิดงาน`):**
   - เมื่อผู้ขายกดยืนยันการรับเงินเรียบร้อย ระบบเปลี่ยนสถานะคำขอเป็น `S7: สำเร็จ / ปิดงาน (Completed)`

---

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria`)
- **`AC-S06-01` (100% Seller Weight Confirmation Block — `REQ-FN-005`):** เมื่อผู้รับซื้อกรอกน้ำหนักจริงแยกตามชนิดวัสดุแล้ว แต่ผู้ขายยังไม่ได้กดยืนยันตัวเลขน้ำหนัก ระบบต้องบล็อกไม่ให้ออกใบสรุปยอดเงิน `100%`
- **`AC-S06-02` (Payment Method Selection — `UC-06`, `UC-10`):** หลังจากผู้ขายกดยืนยันน้ำหนักแล้ว (`S5 -> S6`) ผู้ขายสามารถเลือกวิธีรับเงิน (`เงินสด / QR Code / โอน`) ได้
- **`AC-S06-03` (Digital Receipt & Completion — `SC-03`):** เมื่อผู้ขายกดยืนยันการรับเงิน ระบบต้องออกใบเสร็จดิจิทัลให้ทั้งสองฝ่ายและเปลี่ยนสถานะคำขอเป็น `S7 (Completed)`
