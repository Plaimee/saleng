# ฝั่งผู้ขาย ลำดับที่ 3: ระบบค้นหาและเลือกผู้รับซื้อ (`3. ระบบค้นหาและเลือกผู้รับซื้อ`)

- **อ้างอิงอาร์ติแฟกต์ที่เกี่ยวข้อง:**
  - ตารางแบ่งฟีเจอร์ฝั่ง **`ผู้ขาย`** ลำดับที่ **`3`**
  - ความต้องการที่เกี่ยวข้อง: `REQ-SEC-001`, `REQ-QA-001`, `REQ-UX-001`, `REQ-FN-002`

---

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **แสดงรายชื่อซาเล้ง/ผู้รับซื้อที่ลงทะเบียนและเปิดรับงานในพื้นที่ พร้อมโปรไฟล์และคะแนนรีวิว (`REQ-SEC-001`, `REQ-QA-001`, `REQ-UX-001`):**
   - แสดงตัวเลือก **`"ซาเล้งที่เคยใช้บริการ"`** ไว้บนสุดของรายการให้เลือกนัดซ้ำได้ง่าย (`REQ-UX-001`)
   - ให้ผู้ขายดู **รูปถ่าย ชื่อ สถานะการยืนยันตัวตน (`ยืนยันตัวตนแล้ว 100%` — `REQ-QA-001`) ประวัติการรับซื้อ และคะแนนรีวิว** ของซาเล้งได้ก่อนยืนยันนัดหมายให้เข้าบ้าน (`REQ-SEC-001`)
2. **กรองตามพื้นที่/ระยะทาง, ประเภทยานพาหนะ, ชนิดของที่รับ, และคะแนนรีวิว:**
   - รองรับการกรองรายชื่อผู้รับซื้อในรัศมีพื้นที่ทำการ (`<= 5 กม.` ตาม `REQ-FN-002`)
   - กรองตามประเภทยานพาหนะ (เช่น ซาเล้งสามล้อ หรือรถกระบะสำหรับของชิ้นใหญ่), ชนิดของเก่าที่รับซื้อ, และคะแนนรีวิว
3. **เปิดแชต/โทรด่วนเพื่อสอบถามและเจรจาเป็นรายบุคคล:**
   - เชื่อมต่อกับระบบสื่อสารของฝั่งผู้ซื้อ (`ฝั่งผู้ซื้อ ลำดับที่ 5: ระบบสื่อสาร`) เพื่อให้ผู้ขายแชตหรือโทรด่วนสอบถามรายละเอียดกับซาเล้งได้โดยตรง

---

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria`)
- **`AC-S03-01` (Saleng Profile & KYC Verification Display — `REQ-SEC-001`, `REQ-QA-001`):** ผู้ขายต้องเห็นรูปถ่าย ชื่อ ประวัติการรับซื้อ และสถานะ `"ยืนยันตัวตนแล้ว"` ของซาเล้งครบ 100% ก่อนกดยืนยันนัดหมายให้เข้าบ้าน
- **`AC-S03-02` (Top Pinning for Previous Collectors — `REQ-UX-001`):** หากผู้ขายเคยบันทึกซาเล้งที่เคยใช้บริการไว้ ระบบต้องแสดงรายชื่อ `"ซาเล้งที่เคยใช้บริการ"` ไว้บนสุดของรายการเสมอ
- **`AC-S03-03` (Multi-Criteria Collector Filter & Direct Chat/Call):** ผู้ขายสามารถกรองรายชื่อซาเล้งตามระยะทาง ประเภทยานพาหนะ ชนิดของที่รับ คะแนนรีวิว และกดเปิดแชต/โทรด่วนได้
