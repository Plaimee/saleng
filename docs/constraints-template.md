# แม่แบบไฟล์ข้อจำกัดกลาง (`docs/constraints-template.md`)

ไฟล์จริงของโปรเจกต์อยู่ที่ [`specs/000-shared/constraints.md`](../specs/000-shared/constraints.md) โครงสร้างมาตรฐานประกอบด้วย:

1. **ข้อจำกัดทางเทคนิคและสถาปัตยกรรม (`REQ-CON` / `CC-xx`):** เช่น การทำงานแบบ Offline-first, ขีดจำกัดอุปกรณ์
2. **ข้อจำกัดด้านความปลอดภัย (`REQ-SEC`):** เช่น การยืนยันตัวตน (KYC), การบันทึก Audit Log แบบแก้ไขทับไม่ได้ (Append-only)
3. **ข้อจำกัดด้านข้อมูลและความเป็นส่วนตัว (`REQ-PRV` / `PDPA`):** เช่น การปกปิดพิกัดบ้านเลขที่และเบอร์โทรศัพท์ก่อนรับงานและหลังจบงาน
4. **ข้อจำกัดด้านการปฏิบัติการและระบบภายนอก (`REQ-OP`):** เช่น การสลับใช้ระบบสำรอง (Fallback) เมื่อบริการแผนที่หรือระบบชำระเงินภายนอกขัดข้อง
5. **บันทึกการตัดสินใจระดับสถาปัตยกรรมกลาง (`D-00-xx`):** การตัดสินใจที่มีผลกับทุกฟีเจอร์ในระบบ
