# แผนการทดสอบตรวจรับโดยผู้ใช้ (`docs/acceptance/uat-plan.md`) — โครงการ Saleng (กลุ่ม 2)

เอกสารนี้กำหนดแผนการทดสอบเพื่อตรวจรับระบบ (User Acceptance Test Plan — UAT) สำหรับฟีเจอร์ `UC-04` การจัดการงานและเส้นทางรับซื้อของเก่าของซาเล้ง (Release `R1`)

---

## 1. ขอบเขตและผู้ร่วมตรวจรับ
- **รุ่นที่ตรวจรับ:** Release `R1` (อ้างอิง Baseline `BL-02 / B2`)
- **ผู้ตรวจรับหลัก:**
  1. ตัวแทนซาเล้ง / ผู้รับซื้อรายย่อย (`SH-01`)
  2. ตัวแทนผู้ขายของเก่าตามครัวเรือน (`SH-02`)
  3. เจ้าของผลิตภัณฑ์แพลตฟอร์ม Saleng (`SH-05`)
- **เกณฑ์การผ่านเพื่อลงนามตรวจรับ (Exit Criteria):**
  1. ชุดทดสอบอัตโนมัติ (`pytest`) ผ่านครบ `12 / 12 AC` (`AC-04-01..12`)
  2. การตรวจหน้าจอเทียบ Mockup (`ui-review.md`) ตรงครบ `18 / 18 ข้อตรวจ`
  3. ไม่มีข้อบกพร่องระดับวิกฤต (`S1 Blocker`) หรือระดับรุนแรง (`S2 Major`) ค้างอยู่

---
