# อภิธานศัพท์โดเมนและรหัสสถานะ (`docs/srs/glossary.md`) — โครงการ Saleng (กลุ่ม 2)

เอกสารนี้กำหนดคำศัพท์มาตรฐานภาษาไทยและชื่อตัวแปรที่ใช้ตรงกันทั้งใน `spec.md`, `rules.md`, `models.md`, `mockups/` และโค้ดของระบบ Saleng

---

## 1. คำศัพท์โดเมนหลัก (Domain Terms)

| คำศัพท์ภาษาไทย (ใช้บนหน้าจอและสเปก) | ชื่อในโค้ด / ฐานข้อมูล | คำจำกัดความที่ใช้ตรงกันทั้งโครงการ |
|---|---|---|
| **ซาเล้ง / ผู้รับซื้อรายย่อย** | `Buyer` / `Saleng` | ผู้รับซื้อวัสดุรีไซเคิลรายย่อยที่ผ่านการยืนยันตัวตน (KYC) และใช้แอปเพื่อรับงานตามเส้นทาง (`SH-01`) |
| **ผู้ขายของเก่า** | `Seller` | เจ้าของบ้านหรือร้านค้าย่อยที่โพสต์ขายวัสดุรีไซเคิลผ่านแพลตฟอร์ม (`SH-02`) |
| **ลานรับซื้อของเก่าพันธมิตร** | `ScrapYard` | ร้านหรือลานรับซื้อขนาดใหญ่ที่รับซื้อวัสดุต่อจากซาเล้งและอ้างอิงใบเสร็จดิจิทัลของระบบ (`SH-03`) |
| **ราคาล็อก ณ นัดหมาย** | `locked_unit_price` (`Price Snapshot`) | ราคากลางต่อกิโลกรัม (บาท/กก.) ที่ระบบบันทึกไว้ตายตัวเมื่อใบงานเปลี่ยนเป็นสถานะ `S2 (Matched)` (`REQ-BR-002`) |
| **น้ำหนักประเมิน (กก.)** | `est_weight_kg` | น้ำหนักวัสดุโดยประมาณที่ผู้ขายระบุหรือประเมินจากภาพถ่ายตอนสร้างโพสต์ (`S1`) |
| **น้ำหนักชั่งจริง (กก.)** | `actual_weight_kg` | น้ำหนักวัสดุที่ซาเล้งชั่งด้วยตาชั่งจริงที่หน้างานพร้อมแนบรูปถ่ายหน้าตาชั่งในสถานะ `S4` |
| **ส่วนต่างน้ำหนัก (%)** | `variance_pct` | อัตราส่วนต่างสัมบูรณ์ `abs(actual_weight_kg - est_weight_kg) / est_weight_kg` เทียบกับเกณฑ์ `±15%` (`BR-02`) |
| **ความจุรถซาเล้ง (กก.)** | `max_capacity_kg` | น้ำหนักบรรทุกสูงสุดที่รถซาเล้งคันนั้นรับได้ในหนึ่งรอบวิ่ง (ค่าเริ่มต้น `200.0 กก.` ตาม `BR-03`) |
| **คิวออฟไลน์** | `OfflineSyncQueue` | คิวจัดเก็บธุรกรรมการชั่งและใบเสร็จในอุปกรณ์เมื่อไม่มีอินเทอร์เน็ต ใช้ `idempotency_key` ป้องกันการซิงก์ซ้ำ (`REQ-OP-001`) |
| **โหมดคำนวณระยะทางสำรอง** | `HaversineFallback` | การคำนวณระยะทางจากพิกัดละติจูด/ลองจิจูดคูณตัวคูณถนน `1.35` เมื่อระบบแผนที่ภายนอกไม่ตอบสนอง (`REQ-OP-002`) |

## 2. รหัสสถานะใบงานมาตรฐาน `S1..S9` (`MD-STM-04`)

| รหัสสถานะ | ชื่อสถานะภาษาอังกฤษ | ชื่อสถานะภาษาไทยบนหน้าจอ | ความหมายและเงื่อนไขการเปลี่ยนสถานะ |
|---|---|---|---|
| `S1` | `Posted` | รอผู้รับงาน | ผู้ขายสร้างโพสต์ขายของเก่าเสร็จสิ้น ซ่อนบ้านเลขที่จริงและเบอร์โทรศัพท์ (`REQ-SEC-002`) |
| `S2` | `Matched` | มีผู้รับงานแล้ว / นัดหมายสำเร็จ | ซาเล้งกดรับงานเข้าคิววิ่งและระบบล็อกราคากลาง ณ เวลานัดหมาย (`BR-01`, `REQ-BR-002`) |
| `S3` | `En-Route` | กำลังเดินทาง | ซาเล้งกำลังเดินทางตามลำดับจุดแวะที่คำนวณไว้ (`AC-04-01`) |
| `S4` | `Arrived & Weighing` | ถึงหน้างาน / กำลังชั่งน้ำหนักจริง | ซาเล้งถึงจุดนัดหมายและกำลังบันทึกน้ำหนักชั่งจริงพร้อมถ่ายภาพหน้าตาชั่ง (`AC-04-03`) |
| `S5` | `Re-Quotation Pending` | รอผู้ขายยืนยันราคาใหม่ | น้ำหนักชั่งจริงต่างจากที่ประเมินเกิน `±15%` ระบบส่งยอดเงินใหม่ให้ผู้ขายกดยืนยัน (`AC-04-06`) |
| `S6` | `Settled` | ชำระเงินและออกใบเสร็จแล้ว | น้ำหนักอยู่ในเกณฑ์ `±15%` หรือผู้ขายกดยืนยันใน `S5` แล้ว ระบบคำนวณยอดและออกใบเสร็จดิจิทัล (`AC-04-04`, `AC-04-07`) |
| `S7` | `Completed` | จบงานสมบูรณ์ | ซิงก์ข้อมูลใบเสร็จขึ้นเซิร์ฟเวอร์ครบถ้วนและปกปิดข้อมูลส่วนบุคคลหลังจบงาน (`AC-04-09`, `AC-04-11`) |
| `S8` | `Disputed` | อยู่ระหว่างตรวจสอบข้อพิพาท | ผู้ขายปฏิเสธผลชั่งใน `S5` ระบบล็อกภาพถ่ายตาชั่งและพิกัด GPS ส่งให้ Admin ตัดสิน (`AC-04-08`) |
| `S9` | `Cancelled` | ยกเลิกใบงาน | ใบงานถูกยกเลิกก่อนมีผู้รับงาน หรือยกเลิกตามคำตัดสินของ Admin |
