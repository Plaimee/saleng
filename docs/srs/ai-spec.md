# Data, AI & Agent Specification (`docs/srs/ai-spec.md`) — โครงการ Saleng (กลุ่ม 2)

เอกสารนี้กำหนดขอบเขตความรับผิดชอบของโมดูล AI ช่วยประเมินหมวดวัสดุและอ่านตัวเลขหน้าตาชั่งดิจิทัล (On-Device Scrap Classification & Scale OCR Assistant) รวมถึงมาตรการควบคุมความปลอดภัย (Guardrails) และจุดที่บังคับให้คนตัดสินใจ (Human-in-the-Loop)

---

## 1. ขอบเขตหน้าที่ของ AI vs กฎธุรกิจที่ห้ามใช้ AI เดา (AI Boundary)

| งานที่อนุญาตให้ใช้ AI ช่วยแนะนำ (Assistive AI) | งานที่ห้ามใช้ AI ตัดสินใจเด็ดขาด (ต้องใช้ Deterministic Code / มนุษย์ยืนยัน) |
|---|---|
| 1. **ช่วยจำแนกหมวดวัสดุเบื้องต้นจากรูปถ่ายของผู้ขาย (`UC-02`):** แนะนำว่าภาพที่ถ่ายน่าจะเป็น `ขวดพลาสติกใส PET`, `กระดาษลังลูกฟูก`, หรือ `กระป๋องอะลูมิเนียม` พร้อมค่าความมั่นใจ (`confidence_score`) | 1. **การคำนวณส่วนต่างน้ำหนัก `±15%` (`BR-02`):** ต้องใช้สูตรคณิตศาสตร์ตายตัว `abs(actual - est) / est > 0.15` เท่านั้น ห้ามใช้โมเดลภาษาคำนวณยอดเงิน |
| 2. **ช่วยอ่านตัวเลขจากภาพถ่ายหน้าจอตาชั่งดิจิทัล (Scale OCR ใน `UC-04/UC-05`):** ดึงตัวเลขกิโลกรัมจากภาพถ่ายตาชั่งมาเติมลงช่องกรอกให้ซาเล้งตรวจสอบก่อนกดยืนยัน | 2. **การยืนยันราคาใหม่ (`S5`) และการตัดสินข้อพิพาท (`S8`):** ต้องให้ผู้ขาย (`SH-02`) หรือผู้ดูแลระบบ (`SH-04`) เป็นผู้กดยืนยันเท่านั้น (`REQ-FN-004`, `REQ-FN-006`) |

## 2. มาตรการควบคุมและ Human-in-the-Loop (Guardrails & Fallback)
1. **เกณฑ์ความมั่นใจขั้นต่ำ (`Confidence Threshold >= 0.80`):** หากโมเดล OCR อ่านตัวเลขหน้าตาชั่งได้ค่าความมั่นใจต่ำกว่า `0.80` (เช่น ภาพมืด ย้อนแสง หรือเป็นตาชั่งเข็ม) ระบบต้องไม่กรอกตัวเลขให้อัตโนมัติ และบังคับให้ซาเล้งพิมพ์ตัวเลขด้วยตนเอง (`Manual Input Fallback`)
2. **บังคับคนตรวจสอบก่อนบันทึกเสมอ (Mandatory Human Confirmation):** ตัวเลขที่ OCR อ่านได้เป็นเพียงค่าร่างในช่องกรอก ซาเล้งต้องตรวจดูเทียบกับตาชั่งจริงและกดปุ่มยืนยันด้วยตนเองทุกครั้ง
3. **การประเมินความแม่นยำด้วยชุดข้อมูลทดสอบ (`eval/qa.jsonl`):** ทดสอบด้วยชุดข้อมูลมาตรฐาน 20 เคสใน [`eval/qa.jsonl`](../../eval/qa.jsonl) (ครอบคลุมกรณีภาพชัดเจน ภาพย้อนแสง น้ำหนักอยู่ในเกณฑ์ `±15%` น้ำหนักเกินเกณฑ์ `±15%` และการพยายามปลอมแปลงคำสั่ง Prompt Injection) โดยต้องผ่านเกณฑ์ความถูกต้องของการคัดกรอง `100%` ในส่วนกฎธุรกิจ
