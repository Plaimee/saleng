# รายการงานย่อยที่ทีมแตกเองด้วยมือ (`docs/hand-written/tasks.md`) — ก่อนใช้คำสั่ง `/tasks`

> **หมายเหตุ:** ไฟล์นี้คืองานย่อย 6 ข้อที่ทีมกลุ่ม 2 แตกเองก่อนใช้คำสั่ง `/tasks` ใช้สำหรับเปรียบเทียบกับงาน 13 ข้อที่ AI สร้างใน [`specs/002-route/tasks-compare.md`](../../specs/002-route/tasks-compare.md)

---

## รายการงาน 6 ข้อที่ทีมเขียนเอง

| รหัสงาน | สิ่งที่ต้องทำ | โฟลเดอร์ที่แตะ | เกณฑ์เสร็จงาน |
|---|---|---|---|
| `HW-01` | สร้างโปรเจกต์ FastAPI และตารางฐานข้อมูล `jobs`, `receipts` | `backend/` | รันเซิร์ฟเวอร์ขึ้นและสร้างตารางได้ |
| `HW-02` | เขียน API ค้นหางานในรัศมี 5 กม. และเช็คความจุรถซาเล้ง 200 กก. | `backend/` | ทดสอบดึงงานและบล็อกเมื่อน้ำหนักเกิน 200 กก. ผ่าน |
| `HW-03` | เขียน API อัปเดตสถานะการเดินทาง (`S2 -> S3 -> S4`) | `backend/` | เปลี่ยนสถานะใบงานได้ถูกต้อง |
| `HW-04` | เขียนระบบชั่งน้ำหนักจริง เช็คส่วนต่าง 15% ส่งใบเสนอราคาใหม่ (`S5`) และออกใบเสร็จ (`S6`) | `backend/` | คำนวณราคาถูกต้องและเปลี่ยนสถานะตามเงื่อนไข 15% |
| `HW-05` | ทำระบบเก็บข้อมูลลง LocalStorage เมื่อเน็ตหลุดแล้วส่งขึ้นเซิร์ฟเวอร์ทีหลัง | `frontend/`, `backend/` | บันทึกตอนออฟไลน์และส่งข้อมูลเมื่อต่อเน็ตได้ |
| `HW-06` | สร้างหน้าจอเว็บมือถือสำหรับซาเล้งกดรับงานและกรอกน้ำหนัก | `frontend/` | เปิดหน้าจอและกดใช้งานได้ครบขั้นตอน |
